## 📝 Full Description (完整說明 - 英文)

**PDF Decryptor** is a powerful, lightweight, and privacy-first Android app designed to decrypt password-protected PDF documents quickly and securely. 

Whether you need to unlock a single encrypted PDF or process multiple files in batch, PDF Decryptor handles everything **100% locally on your device**. Your sensitive passwords and confidential documents are never uploaded to the cloud or any external servers.

### 🌟 Key Features:
* 📄 **Batch PDF Decryption**: Select and unlock multiple password-protected PDFs at once without lag.
* 🔑 **Local Password Vault**: Safely save and auto-fill frequently used PDF passwords using an encrypted local Room database.
* 📲 **Seamless Integration**: Open PDFs directly from File Managers, WhatsApp, Email, or Web Browsers with standard System Open/Share intents.
* ⚙️ **Flexible Output Options**: Choose to **Save as Copy** or **Overwrite** existing files effortlessly.
* 🎨 **Clean Material 3 Design**: Modern, responsive Jetpack Compose UI with full Dark Mode & English / Traditional Chinese support.
* 🔒 **100% Offline & Private**: All decryption processes run offline on your device with zero data collection.
