PDF Decryptor (PDDF) 是一款快速、輕量且極度注重隱私的 Android PDF 密碼解除與批次解密工具。

無論您是需要解除單一銀行電子帳單的密碼保護，還是進行大量 PDF 文件批次解密，PDF Decryptor 都能在您的手機上 100% 本地自動化處理。您的機密文件與敏感密碼絕不會上傳至雲端或任何第三方伺服器！

主要特色功能：
• 批次 PDF 密碼解密：一次選取並解密多個受密碼保護的 PDF 文件，背景異步處理快速不卡頓。
• 本地常用密碼庫：加密儲存常用 PDF 密碼，一鍵自動填入，免去重複手動輸入的麻煩。
• 快捷設定面板 (QS Tile) 與快速分享：支援從檔案總管、LINE/WhatsApp、電子郵件直接分享 PDF 開啟解密，或從下拉快捷設定磚快速啟動。
• 彈性儲存模式：自由選擇「另存新檔」或「原檔覆蓋」儲存解密後的 PDF 文件。
• Material 3 現代化介面：採用 Jetpack Compose 打造，支援深色模式與自適應系統語系。
• 100% 離線與隱私安全：完全不要求網路權限，零數據收集、零追蹤、無任何廣告干擾。
