PDF Decryptor (PDDF)

Last updated: August 30, 2026 | Application ID: com.max97k.pddf

Privacy Summary: PDF Decryptor (PDDF) is an open-source, offline-first tool designed with complete privacy in mind. We do not collect, store, transmit, or share any of your personal data, files, or passwords.

1. Zero Data Collection & Transmission

We do not collect, transmit, or store your data on any remote servers.

  • No Internet Permission: The application does not even request the Android INTERNET permission. It has zero capability to transmit data over the network.
  • 100% Local Processing: All PDF decryption, password verification, and document processing happen entirely on your local device hardware using Apache PDFBox Android.
  • No Analytics or Tracking: We do not include any analytics tools, telemetry frameworks, crash reporting trackers, or advertising SDKs (e.g., Firebase Analytics, Google Analytics, Facebook SDK).

2. Storage & File Access

PDF Decryptor uses Android's modern Storage Access Framework (SAF) and system file pickers to access PDF documents:

  • File access is strictly limited to PDF files that you explicitly select.
  • Decrypted PDF files are saved only to the directory you choose on your device storage.
  • Original files are never modified without your instruction.

3. Saved Passwords & Security

If you choose to use the saved password profile feature:

  • Passwords and labels are stored securely in a local, sandboxed SQLite database on your device.
  • Saved password profiles can optionally be protected by Android Biometric Authentication (Fingerprint / Face Unlock).
  • Sensitive credential files and databases are explicitly excluded from Android cloud backups (Google Drive) and device-to-device migration transfers.

4. Third-Party Services & Advertising

  • No Advertisements: PDF Decryptor is 100% free of ads.
  • No Third-Party SDK Data Sharing: We do not integrate with third-party data brokers or marketing services.

5. Children's Privacy

PDF Decryptor does not collect or request any personal information from any user, including children under the age of 13.

6. Open Source Transparency

PDF Decryptor is open source. You can audit the full source code, permissions, and build configuration at any time on GitHub:

https://github.com/Max97k/PDDF

7. Changes to This Privacy Policy

We may update our Privacy Policy as the app evolves. Any modifications will be posted to this page with an updated revision date.

8. Contact Us

If you have questions, concerns, or inquiries regarding this Privacy Policy, please open an issue on GitHub:

https://github.com/Max97k/PDDF/issues

隱私權簡介： PDF Decryptor (PDDF) 是一款開源且離線優先的 PDF 解密工具。我們不會收集、上傳、傳輸或分享您的任何個人資料、PDF 檔案或密碼。

1. 零資料收集與傳輸

我們絕不會在任何外部伺服器上收集、傳輸或儲存您的任何資料。

  • 無需網路權限： 本應用程式甚至未宣告 Android INTERNET 網路權限，完全無法進行任何網路連線與資料傳輸。
  • 100% 裝置端本地處理： 所有 PDF 解密、密碼驗證與文件生成操作均在您的本機裝置上透過 Apache PDFBox Android 完成，檔案絕不離開您的裝置。
  • 無數據分析與追蹤： 本應用程式未包含任何第三方分析工具、遙測追蹤、崩潰回報器或廣告 SDK（例如 Firebase Analytics、Google Analytics 等）。

2. 儲存空間與檔案存取

PDF Decryptor 透過 Android 儲存存取框架（Storage Access Framework, SAF）與系統檔案選擇器讀取與儲存檔案：

  • 僅存取您主動選擇的 PDF 檔案。
  • 解密後的 PDF 檔案只會儲存至您指定的手機目錄中。
  • 絕不會未經授權修改您的原始檔案。

3. 密碼管理與安全性

若您選擇使用「常用密碼」儲存功能：

  • 密碼與標籤資料僅儲存於您手機本機的沙盒資料庫中。
  • 支援 Android 生物辨識驗證（指紋 / 臉部解鎖）保護您的已存密碼。
  • 密碼資料庫已明確設定排除於 Android 雲端備份（Google Drive）與裝置間轉移，避免密碼外洩。

4. 第三方服務與廣告

  • 無廣告： PDF Decryptor 完全無廣告干擾。
  • 無第三方資料共享： 我們絕不向任何行銷或資料分析業者提供使用者資料。

5. 兒童隱私保護

PDF Decryptor 不會主動或被動收集任何使用者的個人資訊（包含 13 歲以下的兒童）。
